# Coverage tracker

One row per planned batch (see `docs/DATA_PIPELINE.md`). Status is one of `todo`,
`in progress` (with branch), `in review` (with pull request), or `done`. Work the
highest-priority `todo` row first. Counts are filled in when a batch is opened for review.

Priority 1 covers the eras the timeline already shows most, so each batch replaces
uncited generated links with cited ones. Priority 2 and 3 fill regions and themes the
Wikidata import covers thinly.
